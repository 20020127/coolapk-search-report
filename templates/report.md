# 酷安话题报告模板

> 使用说明：按本骨架填充。**三项元数据（样本量 / 抓取时间 / 数据说明）缺一不可**，它们是这份报告可信度的底线。

---

## 数据说明（必填，置于报告开头）

| 项 | 内容 |
| --- | --- |
| 数据来源 | 酷安搜索「{关键词}」（`search --pages {N}`） |
| 样本量 | 搜索命中 {X} 篇 → 精读 {Y} 篇 → 评论 {Z} 条 |
| 抓取时间 | {YYYY-MM-DD HH:MM} |
| 登录状态 | 已登录（正文+评论）/ **未登录（仅正文，评论未获取）** |
| 局限 | {如：评论区未获取 / 部分帖子接口报错 / 样本偏少，结论仅供参考} |

> 未登录时必须显式写明：以下结论仅基于帖子正文，不代表评论区的观点分布。
